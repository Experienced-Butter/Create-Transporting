## 正文（粘贴到「介绍」栏）

### 概述

**机械动力：通勤运输** 是一个面向 Create（机械动力）的附属模组，为 1.21.1 / NeoForge 编写。
它把原版的村庄当作铁路系统的**客运起点**：村民会被统计成「旅客」，由列车按站点顺序接送，
车主按运输距离获得报酬，列车出事故时车主需要赔偿。

整个系统的闭环是：

```
村庄站点（普查 → 旅客名单）
      ↕
站台路灯（把村庄站点与列车站点绑定）
      ↕
旅客座垫（放在列车上，每个座垫载一名旅客）
      ↕
列车到站 → 下车结算 → 候车旅客上车
      ↕
交易站（把报酬换成硬币、把硬币存回资产）
```

### 前置与安装

1. 为 Minecraft **1.21.1** 安装 **NeoForge 21.1.0** 或更高版本；
2. 安装 **Create 6.0.10**（或其 6.0.x 版本）；
3. 把本模组的 jar 放入 `mods/` 文件夹；
4. 客户端与服务端都需要安装（本模组添加了方块、物品与服务端逻辑）。

### 快速上手

1. 在村庄里放下**村庄站点**并右键打开界面。站点会对村庄进行一次普查（统计村民、床、工作站点数量），
   普查完成后状态变为「已激活」，界面里开始陆续出现旅客；
2. 在村庄站点附近（30 格内）放一个 Create 的**列车站点**，再放一个**站台路灯**；
3. 右键路灯，把上方槽位绑定到村庄站点、下方槽位绑定到列车站点，路灯亮起即表示绑定有效；
4. 用 Create 的列车在**旅客座垫**上组一列客运列车，让它在两个站点之间运行；
5. 列车停靠时，站内旅客按顺序坐进空座垫；再次到站时，满足条件的旅客下车，车主获得报酬。

### 方块

**村庄站点（Village Station）**
- 普查**有间隔**，村庄越大间隔越长，避免持续扫描；普查会在区块未全部加载时推迟，绝不会强行加载区块；
- 界面显示村庄状态、村民数、有职业人数、床与工作站点数量、旅客名单、下一次普查倒计时、本小时已结算金额；
- 旅客名单支持**鼠标滚轮滚动**，鼠标悬停可查看目的、耐心与起点；
- 「立即普查」按钮可以提前触发一次普查，普查进行中按钮会置灰；
- 一个村庄只允许一个站点，站点之间还有最小间距限制；
- 通过**扳手潜行右键**可以完整拆下（内部旅客会随方块一起消失，不会掉出物品）。

**站台路灯（Platform Lamp）**
- 一座路灯只能绑定一个村庄站点 + 一个列车站点，两者距离上限 30 格（可配置）；
- 绑定前会检查目标类型、区块是否加载、是否已被其他路灯占用；
- 只有村庄站点处于激活状态时路灯才会亮；
- 打开界面后 **5 秒内**会在世界中用描边框标出两个被绑定的方块（绿=村庄站点，黄=列车站点，蓝=路灯本身）。

**旅客座垫（Passenger Seat，16 色）**
- 放在世界里就是 Create 的座垫；放在列车上时，每个座垫承载一名旅客；
- 已载客的座垫玩家无法坐下，潜行右键可以查看乘车的旅客信息；
- 载客时座垫上会显示一名**村民**，其服饰对应旅客的出行目的：
  - 贸易 → 匠人职业（盔甲匠 / 武器匠 / 工具匠）；
  - 旅行 → 温和或脑力职业（图书管理员 / 制图师 / 牧羊人）；
  - 搬迁 → 无职业村民服饰；
  - 服饰基底跟随旅客**来源村庄所在生物群系**（雪原村庄 → 雪原样式）。

**交易站（Trade Station）**
- 界面里可以操作自己的背包与快捷栏；
- 按钮切换「放入 / 取出」两种模式：
  - 放入模式：槽位里的硬币转换为玩家资产；
  - 取出模式：玩家资产自动铸造成硬币放入槽位；
- **只有被红石信号充能时才会进行转换**，未充能时完全不动作；
- 顶部铜灯会随充能状态在亮/暗之间切换（仅外观变化，不改变光照等级）。

### 旅客与结算

- 旅客分为三种出行目的：**旅行 / 搬迁 / 贸易**，概率随村庄就业率变化；
- 每位旅客有 1–8 点耐心，另有小概率出现「超耐心」旅客（10 点，站点内数量有上限）；
- 每次名单刷新，站内非超耐心旅客的耐心会-1（间隔可配置），耐心归零的旅客会离开；
- 列车到站时：
  - 先结算下车（贸易旅客在有职业的村庄下车、搬迁旅客在空闲村庄下车、耐心归零强制下车）；
  - 车主按 **目的基础价 × 耐心系数 × 距离曲线 × 线路疲劳** 获得报酬；
  - **距离不超过 256 格的行程不计收入**（回到出发站或附近站点没有收益）；
  - 有单次封顶与每小时封顶，防止无限刷钱；
- 每段线路有疲劳系数：同一路线短时间内反复跑，收益会下降（有下限）。

### 事故与赔偿

列车脱轨或列车被拆解时，车上旅客会被清空，并按事故地点到起点的距离从车主账户扣款；
账户余额允许为负（欠债），欠债状态下交易站不会铸币。

### 配置

所有机制都可以在 `config/create_village_transit-server.toml` 中调整，共 **63 项**，分为：

`[village]` 村庄判定与普查 · `[station]` 站点限制 · `[passenger]` 旅客与耐心 ·
`[preference]` 下车偏好 · `[reward]` 报酬与封顶 · `[lamp]` 路灯约束 ·
`[economy]` 货币与交易站 · `[seat]` 座垫规则 · `[debug]` 日志与诊断

也可以在游戏内 **Mods 列表 → 本模组 → Config** 中直接调整。

### 管理员命令

```
/cvtransit status      查看所有站点状态
/cvtransit selftest    放置一个测试站点并跑一次完整普查
/cvtransit simulate    用合成数据跑一次到站结算（含入账与上车）
/cvtransit board       跑一次上车逻辑
/cvtransit accident    跑一次事故扣款（允许欠债）
/cvtransit econ        跑一次货币存取（先扣后铸、欠债禁止铸币）
/cvtransit lamp        跑一遍路灯绑定的全部成功/失败分支
/cvtransit links       列出所有路灯与其绑定状态
/cvtransit trains      列出当前列车与在车旅客
/cvtransit chunks      查看已加载区块计数（确认不会强加载）
/cvtransit markers     验证玩家占座标记的生成与清除
/cvtransit persist     存档写入与读回校验
/cvtransit perf        查看调度器单 tick 耗时
/cvtransit packet      查看站点数据包大小
```
